# Launcharr Release Announcement

## Headline

Launcharr `v0.2.63` is now available

## Short Summary

Launcharr `v0.2.63` fixes local account management and tightens session handling.

## What's New

- **Local account management works again**: saving your profile and adding, re-roling, or deleting a local user no longer returns a server error. Changing a local account password works again.
- **Visible password validation**: the profile password fields reject a too-short password in the browser instead of silently failing.
- **Stale sessions are dropped**: a session for a local account that no longer exists (for example after wiping the container and files) is invalidated instead of appearing to still be signed in.
- **Session secret guard**: Launcharr warns loudly at startup if `SESSION_SECRET` is left at the example placeholder.

## Why It Matters

- Admins can manage local users and reset passwords without hitting a 500.
- A deleted local user can no longer retain an active session or admin view.
- Operators are nudged off the insecure default secret that let cookies survive redeploys.

## Upgrade Notes

- Docker image: `mickygx/launcharr:0.2.63`
- Supplementary tag: `mickygx/launcharr:latest`
- No migration steps required. Update and restart.
- Set `SESSION_SECRET` away from the placeholder (`openssl rand -hex 32`) if you have not already.
