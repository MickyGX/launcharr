# Launcharr Release Announcement

## Headline

Launcharr `v0.2.61` is now available

## Short Summary

Launcharr `v0.2.61` fixes Dockhand widget stats for live multi-environment Dockhand installs.

## What's New

- **Dockhand widget fix**: container and stack metrics now query each Dockhand environment with the required `env` parameter.
- **Accurate counts**: running, stopped, container, stack, and environment totals now aggregate across accessible Dockhand environments.
- **Regression coverage**: added focused tests for Dockhand metric parsing and fallback behavior.

## Upgrade Notes

- Docker image: `mickygx/launcharr:v0.2.61`
- Supplementary tags: `mickygx/launcharr:latest`
- No migration steps required. Update and restart.
