# Launcharr Release Announcement

## Headline

Launcharr `v0.2.62` is now available

## Short Summary

Launcharr `v0.2.62` adds qBittorrent API key authentication for qBittorrent 5.2+.

## What's New

- **qBittorrent API key login**: set an API key in qBittorrent settings and Launcharr authenticates with a Bearer token, with no username/password login round-trip.
- **Works with older versions**: leave the key blank to keep using username/password on qBittorrent versions before 5.2.
- **Queue and widget support**: the download queue and dashboard widget both use the API key when one is set.

## Upgrade Notes

- Docker image: `mickygx/launcharr:v0.2.62`
- Supplementary tags: `mickygx/launcharr:latest`
- No migration steps required. Update and restart.
