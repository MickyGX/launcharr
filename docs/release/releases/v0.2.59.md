# Changelog

## [v0.2.59] - 2026-06-07

### Summary

- Added Dockhand as a widget-only built-in integration with default app metadata, a dedicated icon, API token settings, and widget metrics for Docker management dashboards.
- Fixed SABnzbd widget metric selection persistence by matching the selectable metric keys to the stats data Launcharr actually returns.
- Fixed built-in app icon resolution when a persisted app entry still contains the generic `/icons/app.svg` fallback.

### Added

- Added a hidden built-in `Dockhand` app definition under the `System` category with launch/settings access for admins and multi-instance support.
- Added Dockhand widget stats using the Dockhand dashboard, containers, stacks, and environments API endpoints.
- Added Dockhand API token fields to both app-settings surfaces, with helper text for Dockhand profile API tokens.
- Added the uploaded Dockhand icon asset at `/icons/dockhand.png`.

### Fixed

- Fixed SABnzbd widget configuration so the metric picker now exposes `Queued`, `Speed`, and `Remaining`, matching the widget stats keys `queued`, `speed`, and `sizeleft`.
- Fixed persisted generic icons so built-in apps can fall back to their catalog/default icon when an older saved config still contains `/icons/app.svg`.

### Changed

- Updated the supported-apps wiki totals and matrix to include Dockhand as a widget-stats-only integration.

### Upgrade Notes

- No schema migration is required. Update and restart Launcharr.
- Dockhand widgets require the Dockhand app URL/local URL and, when your Dockhand instance requires it, a Dockhand API token from Profile -> API tokens.
- SABnzbd widgets using the previous `queue` metric should be reviewed and re-saved if you want the new `Queued` or `Remaining` metric selections.
