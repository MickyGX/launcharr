# Launcharr Release Announcement

## Headline

Launcharr `v0.2.59` is now available

## Short Summary

Launcharr `v0.2.59` adds Dockhand widget support and fixes widget metric/icon handling for existing dashboards.

## What's New

- **Dockhand widgets**: Dockhand is now available as a widget-only built-in integration with a dedicated icon, API token settings, and metrics for containers, stacks, and environments.
- **SABnzbd metric fixes**: SABnzbd widget selections now use the same keys returned by the stats endpoint, preventing saved metric choices from being dropped.
- **Icon fallback fix**: persisted generic app icons no longer block built-in apps from resolving their real default icon.

## Upgrade Notes

- Docker image: `mickygx/launcharr:v0.2.59`
- Supplementary tags: `mickygx/launcharr:latest`
