# Launcharr v0.2.61

## Summary

- Fixed Dockhand widget stats so container and stack metrics are collected from each configured Dockhand environment.
- Preserved dashboard-stat fallbacks for Dockhand responses that expose aggregate counts directly.
- Added regression coverage for Dockhand metric aggregation.

## Fixed

- Fixed Dockhand widget requests calling `/api/containers` and `/api/stacks` without an environment. Launcharr now loads `/api/environments` first, then queries `api/containers?env=<id>&all=true` and `api/stacks?env=<id>` for each environment.
- Fixed Dockhand widgets reporting the environment count while leaving running, stopped, containers, and stacks at `0` on live Dockhand instances.

## Changed

- Extracted Dockhand widget metric parsing into testable helpers.
- Added tests for Dockhand environment ID extraction, list response handling, multi-environment aggregation, and dashboard-stat fallbacks.

## Upgrade Notes

- No schema migration is required. Update and restart Launcharr.
- If Dockhand widget values still look stale after upgrading, refresh the dashboard or restart the Launcharr container so the updated widget endpoint is used.
