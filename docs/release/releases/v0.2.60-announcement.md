# Launcharr Release Announcement

## Headline

Launcharr `v0.2.60` is now available

## Short Summary

Launcharr `v0.2.60` fixes ARR calendar loading for reverse-proxy path-prefix setups.

## What's New

- **ARR calendar fix**: calendar fallback requests now preserve configured `/sonarr` and `/radarr` path prefixes instead of stripping them.
- **More reliable proxy fallback**: calendar cards can recover correctly when Launcharr's same-origin ARR proxy is unavailable.
- **Regression coverage**: added a focused client-side test for calendar fallback URL generation.

## Upgrade Notes

- Docker image: `mickygx/launcharr:v0.2.60`
- Supplementary tags: `mickygx/launcharr:latest`
- No migration steps required. Update and restart.
